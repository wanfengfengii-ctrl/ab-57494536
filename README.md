# 环形接驳板回流线排布（Ring Return Wiring）

海底观测设备回收场景的纯前端工具：在环形接驳板上为每个裸露端点安排**恰好一条**
回流线，避免板内导线交叉，并在**全部可行配对**中取最优。

- 端点按**圆周顺序**排列，编号唯一，端点数须为偶数；
- 仅允许在给定候选对之间连线，每条线有**非负整数损耗**；
- 每个端点恰好连接一次，选中的弦**不得在圆内相交**；
- 系统通过区间 DP 完整比较全部可行不交叉完美匹配，判据依次为：
  1. **总损耗最低**；
  2. **按端点编号升序**得到的“配对另一端序列”**字典序最小**；
- 逐线标注损耗，并标出每条候选弦与哪些候选弦在圆内冲突（相交）；
- 端点数为奇数、候选自连、重复无向候选、引用不存在端点、损耗非法时，
  反馈会**定位到具体行与字段**；
- 无可行配对时不保留旧结论；**任何模型修改都会立即撤下已生成的连线**。

## 本地开发

```bash
npm install
npm run dev       # 开发服务器（Vite）
npm run test      # Vitest 单元测试（含与暴力枚举的对拍）
npm run build     # 类型检查 + 生产构建到 dist/
npm run preview   # 本地预览生产构建
```

## 数据格式（可编辑 / 导入 / 导出 JSON）

```json
{
  "endpoints": [
    { "id": "E1" },
    { "id": "E2" }
  ],
  "candidates": [
    { "a": "E1", "b": "E2", "cost": 3 }
  ]
}
```

- `endpoints` 的数组顺序即**圆周顺序**（从 12 点方向起顺时针排布）；
- `endpoints` 元素也可以直接写字符串 `"E1"`；
- 候选为**无向对**（`a`/`b` 顺序任意），`cost` 为非负整数。

## 算法说明

区间 DP：对圆周顺序区间 `[l,r]`，最左端点 `l` 只能与奇数步长外的 `k` 相连，
弦 `(l,k)` 将区间切成互不相交的 `[l+1,k-1]` 与 `[k+1,r]`。
只有两个子区间都存在可行完美匹配时该选择可行。DP 同时统计可行配对总数
（完全图时等于 Catalan 数，已由测试对拍验证），并按“总损耗 → 编号升序
配对序列字典序”择优后回溯出选中弦。

## Docker

镜像为多阶段构建：`node:22-alpine` 构建静态资源，`nginx:1.27-alpine` 提供
静态服务（SPA 回退 + `/healthz` 健康检查端点）。

```bash
# 宿主机端口可通过 WEB_PORT 配置（默认 8080）
WEB_PORT=9090 docker compose up -d --build web
curl http://localhost:9090/healthz   # -> ok
```

### 一次性 verify 服务

`verify` 服务完成**构建、代码测试及 HTTP 冒烟**后自行退出，并以退出码报告结果：

```bash
docker compose build
docker compose run --rm verify
# 全部通过输出 VERIFY_OK 且退出码为 0；任一步失败退出码非 0
```

它会等待 `web` 服务健康后，检查 `http://web/healthz` 与首页内容。
